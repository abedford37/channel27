CHANNEL 27 — Embed Test

Each tile embeds a candidate YouTube video the way the site would. If it plays, it embeds — set that record to active: true. If it shows "Video unavailable / Watch on YouTube," the owner blocked embedding — leave it inactive and the procedural cartoon covers it.

⚠ Serve this page over http(s) — do not open it from file://. A file:// page sends no origin, so YouTube rejects every embed with Error 153 (video player configuration error) — which looks like the videos are blocked when they aren't. Run python -m http.server in the project root and open http://localhost:8000/tools/embed-test.html, or view this on your GitHub Pages deploy. If you see 153 on every tile, that's the origin, not the videos.
How to read the results
  • Plays / shows a play button → embeddable. Mark Pass.
  • "Video unavailable" / "Watch on YouTube" → the owner disabled embedding for that specific video. Mark Fail; leave active: false.
  • "Error 153" on every tile → you're on file:// or a referrer-stripping context. Not a verdict on the videos — serve the page and reload.
  • Confirm it's the right clip — a valid ID pointing at the wrong video is still wrong.
  • When done, flip only the winners to active: true in content/media.js.
  • Reusable for other channels: edit the VIDEOS array at the bottom of this file.
